## About
#### What is Fluffy Toolkit?
Fluffy Toolkit is a toolkit that contains a bunch of modules and additions that were created overtime by The PFU's where they are directly within the robot's code so no external programs like [Imitate](https://github.com/Turtlerock0010/Imitate) or PI vision systems are going to be put into it.
